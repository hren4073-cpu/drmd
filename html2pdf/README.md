# html2pdf — конвертер HTML → PDF для Windows

Консольная утилита для Windows, которая конвертирует HTML‑файлы в PDF с
**идеальным сохранением вёрстки**: современный CSS (flexbox, grid,
медиа‑запросы), изображения, шрифты и **JavaScript‑рендеринг** (динамические
элементы попадают в PDF). Под капотом — настоящий **headless Chromium**
(Puppeteer), а не устаревший `wkhtmltopdf`.

## Возможности

- 🎯 Полная верность вёрстки — рендерит тот же движок, что и Chrome.
- 🖼 Локальные файлы и **папки сайта** (скачанные через HTTrack/wget):
  относительные ссылки (`images/pic.jpg`, CSS, шрифты) подхватываются
  относительно расположения HTML.
- 📁 Три режима: одиночный файл, массовая конвертация папки (с сохранением
  структуры подпапок), список файлов из текстового файла.
- 📚 `--merge` — объединение всех PDF в один документ с **оглавлением и
  закладками** (по `<title>` / `<h1>`).
- ⚙️ Настройки PDF: формат (A4/Letter/…/из CSS), поля, масштаб, фон,
  ориентация, печатные стили, media type.
- 🚀 Параллельная обработка (`--concurrency`) для тысяч файлов.
- 📊 Прогресс‑бар, таймер, итоговый отчёт и файл лога.
- 🛡 Битые/зависшие файлы пропускаются по таймауту и пишутся в лог — пакет
  не падает целиком.
- 🪟 Поддержка **длинных путей Windows** (> 260 символов) и кириллицы.
- 📦 Самодостаточность: Chromium **скачивается автоматически при первом
  запуске** и кладётся рядом с `.exe` (утилита остаётся портативной).

## Установка и сборка `.exe` (для не‑программиста)

1. Установите **Node.js 18 LTS или новее** с https://nodejs.org (галочка
   «Add to PATH» при установке).
2. Скачайте/распакуйте этот репозиторий, откройте папку `html2pdf` в
   «Командной строке» (cmd) или PowerShell.
3. Выполните по очереди:

   ```bat
   npm install
   npm run build
   ```

4. Готово — в папке появится **`html2pdf.exe`**.

> При **первом** запуске `html2pdf.exe` один раз скачает Chromium (~150 МБ) в
> подпапку `chromium` рядом с exe. Дальше интернет не нужен. Если хотите
> положить exe на другую машину «офлайн» — копируйте его **вместе с папкой
> `chromium`**.

### Сборка без exe (просто запуск)

```bat
npm install
npm run build:ts
node dist/index.js examples\sample.html out.pdf
```

## Использование

### Одиночный файл

```bat
html2pdf.exe input.html output.pdf
```

Если выходной путь не указан — PDF создаётся рядом с HTML.

### Массовая конвертация папки (структура подпапок сохраняется)

```bat
html2pdf.exe --input-dir "C:\my_site" --output-dir "C:\pdfs"
```

### Объединение всех PDF в один документ с оглавлением

```bat
html2pdf.exe --input-dir "C:\my_site" --output-dir "C:\pdfs" --merge
```

### Список файлов из текстового файла

`files.txt` — по одному пути на строку (строки с `#` игнорируются):

```bat
html2pdf.exe --list files.txt --output-dir "C:\pdfs"
```

### Параллельная обработка тысяч файлов

```bat
html2pdf.exe --input-dir "C:\big_site" --output-dir "C:\pdfs" --concurrency 8
```

### Имя PDF из заголовка страницы (`<title>` / `<h1>`)

```bat
html2pdf.exe --input-dir "C:\my_site" --output-dir "C:\pdfs" --name-by-title
```

### Настройка формата, полей, масштаба

```bat
html2pdf.exe in.html out.pdf --format A4 --margin-top 15mm --margin-bottom 15mm --scale 0.9
```

### Печать как «на экране» + свои стили печати

```bat
html2pdf.exe in.html out.pdf --media screen --user-css print.css
```

## Все опции

| Опция | По умолчанию | Описание |
|---|---|---|
| `<input> <output>` | — | Одиночный режим: вход и выход. |
| `--input-dir` | — | Папка с HTML для массовой конвертации. |
| `--output-dir` | — | Папка для PDF (структура подпапок сохраняется). |
| `--list` | — | Текстовый файл со списком HTML (по строке). |
| `--ext` | `.html,.htm` | Расширения при обходе папки. |
| `--concurrency` | `4` | Число параллельных конвертаций. |
| `--name-by-title` | `false` | Имя PDF из `<title>`/`<h1>`. |
| `--merge` | `false` | Объединить всё в один PDF с оглавлением. |
| `--merge-file` | `<output-dir>/_merged.pdf` | Путь объединённого PDF. |
| `--format` | `A4` | `A4`, `Letter`, `Legal`, `A3`, … или `default` (формат из CSS `@page`). |
| `--margin-top/bottom/left/right` | `0` | Поля, напр. `10mm`, `1in`, `20px`. |
| `--scale` | `1.0` | Масштаб `0.1`–`2.0`. |
| `--no-background` | (фон вкл.) | Отключить печать фонов/графики. |
| `--landscape` | `false` | Альбомная ориентация. |
| `--user-css` | — | Файл с печатными CSS‑стилями. |
| `--media` | `print` | `print` или `screen`. |
| `--wait` | `300` | Доп. ожидание после загрузки, мс (для тяжёлого JS). |
| `--timeout` | `60000` | Таймаут на файл, мс (защита от зависших скриптов). |
| `--log` | `<output-dir>/html2pdf.log` | Файл лога. |
| `--quiet` | `false` | Тихий режим. |
| `--help`, `--version` | — | Справка / версия. |

Код возврата: `0` — все успешно, `1` — были ошибки конвертации, `2` —
фатальная ошибка.

## Как это устроено

- **`src/browser.ts`** — гарантирует наличие Chromium (через
  `@puppeteer/browsers`), скачивает при первом запуске в портативный кэш.
- **`src/converter.ts`** — запускает Chromium (`puppeteer-core`), грузит HTML
  как `file://` (относительные ресурсы работают), ждёт `networkidle` + JS,
  печатает в PDF.
- **`src/merge.ts`** — склейка PDF (`pdf-lib`) с оглавлением и закладками;
  на Windows для кириллицы в оглавлении автоматически берётся Arial из
  `C:\Windows\Fonts`.
- **`src/cli.ts`** — разбор аргументов (`yargs`).
- **`src/index.ts`** — оркестрация: список задач, параллелизм (`p-limit`),
  прогресс‑бар (`cli-progress`), отчёт и лог.
- **`src/util.ts`** — длинные пути Windows (`\\?\`), обход папок, имена файлов.

## Замечания

- Утилита **не** использует `wkhtmltopdf` — современный CSS рендерится
  корректно.
- Для очень тяжёлых SPA увеличьте `--wait` (например, `--wait 2000`).
- На не‑Windows ОС оглавление слияния использует встроенный шрифт
  Helvetica (кириллица в самом TOC заменяется), но **сами PDF и закладки**
  поддерживают кириллицу полностью. На Windows TOC тоже кириллический.
